## このツールが必要な理由

サイバーフェイスの仕事は通常、プレイヤー名から始まり、ID、フォルダーパス、名簿チェックで終わります。ブラウザーはこれらの手順を 1 か所に保持し、モッダーが編集中の名簿に関連するレコードのみをエクスポートできるようにします。

## 初回の一連の流れ

1. **NBA 2K27 サイバーフェイスID一覧** を開き、検出された NBA 2K27 のビルドまたはデータ元を確認します。
2. 入力またはプロファイルを選び、今回のテストに関係しない初期値は変えずに **検索可能なプレーヤー ID インデックス** を設定します。
3. プレビューまたはステータス欄で **ルーキーフィルターとロスターフィルター** を確認し、バージョン、フィルター、検出の警告を解消します。
4. 操作を一つだけ実行します。二つ目の設定を変える前に、表示結果をプレビューと比較してください。
5. プロファイルまたは結果を保存し、比較や復元に使える **modフォルダーとエクスポートのメモ** を残します。

## 開始前の準備

- **プレーヤーまたは名簿フィルター** を用意し、対象の NBA 2K27 プロファイルまたはセッションのものか確認します。
- プロファイルを変更する前に、現在のゲーム／クライアントビルドまたはデータ日付を控えます。
- 前回の結果を上書きしないよう、**CSVまたはコピーしたID** の保存先を決めます。
- まず **検索可能なプレーヤー ID インデックス** を短時間だけ試し、元のセーブ、プロファイル、比較結果を残してください。

## 画面の見方

- **01.** チーム、クラス、ステータスのフィルターを使用して名簿を検索します。
- **02.** サイバーフェイス ID と名簿ソースを含むプレーヤー表。
- **03.** 選択したレコードのプレビューとターゲット ファイル パス。
- **04.** テーブル全体をエクスポートせずに、1 人のプレーヤーの ID をコピーするアクション。
- **05.** MOD プロジェクトまたはロスター更新用のフィルターされたエクスポート。

## できること

- **検索可能なプレーヤー ID インデックス.** スペルの正確な一致を強制せずに、プレイヤーの名前と ID を検索します。

- **ルーキーフィルターとロスターフィルター.** 名簿、チーム、クラス、または記録ステータスによってテーブルを絞り込みます。

- **modフォルダーとエクスポートのメモ.** 1 つのクリーンな ID をコピーするか、現在フィルターされているレコードをエクスポートします。

## 結果の読み方

ID をその名簿ソースおよびステータスとともに使用します。カスタム名簿でレコードを再利用したり、チーム間でプレーヤーを移動したりする場合、プレーヤー名が一致するだけでは十分ではありません。フィルタリングされたテーブルは、1 つのサンプル レコードを開いて MOD が予期するターゲット フォルダーを確認した後にのみエクスポートします。

## トラブルシューティング

> **よくある不具合:** サイバーフェイスが間違ったプレーヤーにロードされる.

### 間違ったプレイヤーがフェイスを受け取ります

名簿ソースとプレーヤー ID を一緒に確認してください。重複した名前が複数の名簿セットに存在する可能性があります。

### プレイヤーが行方不明です

チームとルーキーのフィルターを削除し、選択した名簿データを更新します。

### エクスポートされたパスが間違っています

ID をコピーまたはエクスポートする前に、選択したレコードの mod フォルダー ルートを確認してください。

## データと復元

データベースでは名簿ファイルを変更する必要はありません。フィルタリングされた ID を別の MOD ワークスペースにエクスポートし、エクスポート時にソース ロスター ラベルを保持します。

<sub>自動化や変更機能は、ゲームのルールとセッション形式で許可されている場合にのみ使用してください。</sub>

## ゲーム更新後の確認

- [ ] 名簿ソースを更新し、その日付またはバージョンをメモします。
- [ ] 既知のプレーヤーを 1 人検索して、ID とチームがまだ並んでいることを確認します。
- [ ] 更新後に名簿、新人、およびステータスのフィルターを再適用します。
- [ ] 最後に検証された ID リストを上書きするのではなく、新しいエクスポートを作成します。
