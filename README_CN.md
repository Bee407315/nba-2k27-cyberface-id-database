## 为什么需要这个工具

Cyberface 工作通常以玩家姓名开始，以 ID、文件夹路径和名单检查结束。浏览器将这些步骤保留在一处，并让模组制作者仅导出与他们正在编辑的名册相关的记录。

## 完成第一次使用

1. 打开 **NBA 2K27 面补 ID 查询**，确认检测到的 NBA 2K27 版本或数据源。
2. 选择输入或配置，只设置 **可搜索的玩家 ID 索引**，暂时保留与本次测试无关的默认值。
3. 在预览或状态面板检查 **新秀和名单过滤器**，处理版本、筛选或识别警告。
4. 只执行一次可控操作。在修改第二项设置之前，将实际结果与预览进行对比。
5. 保存配置或导出结果，并保留 **mod文件夹和导出注释** 以便对比或恢复。

## 开始之前

- 准备好 **球员或名单过滤器**，并确认它属于目标 NBA 2K27 配置或会话。
- 更改配置之前，记录当前游戏/客户端版本或数据日期。
- 提前选择 **CSV 或复制的 ID** 的保存位置，避免覆盖上一次结果。
- 先用 **可搜索的玩家 ID 索引** 进行一次短测试，并保留原始存档、配置或对比记录。

## 如何理解结果

将 ID 与其名册来源和状态一起使用。当自定义名单重复使用记录或在球队之间移动球员时，匹配的球员姓名是不够的。仅在打开一条示例记录并检查 mod 所需的目标文件夹后导出过滤表。

## 故障排查

> **常见故障:** 网络面孔加载到错误的玩家上.

### 错误的玩家收到一张脸

一起查看名单来源和玩家ID；名册组中可能存在重复的姓名。

### 一名球员失踪

删除球队和新秀过滤器，然后刷新选定的名单数据。

### 导出的路径错误

在复制或导出 ID 之前，请检查所选记录中的 mod 文件夹根目录。

## 数据与恢复

数据库不需要更改名册文件。将过滤后的 ID 导出到单独的 mod 工作区中，并在导出时保留源名册标签。
