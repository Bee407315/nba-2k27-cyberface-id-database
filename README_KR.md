## 이 도구가 필요한 이유

사이버페이스 작업은 일반적으로 플레이어 이름으로 시작하여 ID, 폴더 경로 및 명단 확인으로 끝납니다. 브라우저는 해당 단계를 한 곳에 보관하고 모더가 편집 중인 명단과 관련된 기록만 내보낼 수 있도록 합니다.

## 첫 실행 전체 과정

1. **NBA 2K27 사이버페이스 ID 목록**을 열고 감지된 NBA 2K27 빌드 또는 데이터 원본을 확인합니다.
2. 입력이나 프로필을 선택하고 이번 테스트와 관계없는 기본값은 유지한 채 **검색 가능한 플레이어 ID 인덱스**을 설정합니다.
3. 미리보기나 상태 패널에서 **신인 및 명단 필터**을 확인하고 버전, 필터 또는 감지 경고를 해결합니다.
4. 제어 가능한 작업 하나만 실행합니다. 두 번째 설정을 바꾸기 전에 실제 결과를 미리보기와 비교하세요.
5. 프로필이나 결과를 저장하고 비교 또는 복구에 사용할 **모드 폴더 및 내보내기 노트**을 남겨 둡니다.

## 시작 전 준비

- **플레이어 또는 명단 필터**을 준비하고 대상 NBA 2K27 프로필 또는 세션의 데이터인지 확인합니다.
- 프로필을 변경하기 전에 현재 게임/클라이언트 빌드 또는 데이터 날짜를 기록합니다.
- 이전 결과를 덮어쓰지 않도록 **CSV 또는 복사된 ID**의 저장 위치를 정합니다.
- 먼저 **검색 가능한 플레이어 ID 인덱스**을 짧게 시험하고 원본 세이브, 프로필 또는 비교 기록을 보관하세요.

## 화면 구성

- **01.** 팀, 클래스, 상태 필터를 사용한 명단 검색.
- **02.** 사이버페이스 ID와 명단 소스가 포함된 플레이어 테이블입니다.
- **03.** 대상 파일 경로가 포함된 선택된 기록 미리보기.
- **04.** 전체 테이블을 내보내지 않고 한 플레이어에 대한 ID 복사 작업입니다.
- **05.** 모드 프로젝트 또는 명단 업데이트를 위해 필터링된 내보내기입니다.

## 주요 기능

- **검색 가능한 플레이어 ID 인덱스.** 정확한 철자 일치를 강요하지 않고 플레이어 이름과 ID를 검색합니다.

- **신인 및 명단 필터.** 명단, 팀, 클래스 또는 기록 상태별로 테이블의 범위를 좁힙니다.

- **모드 폴더 및 내보내기 노트.** 하나의 클린 ID를 복사하거나 현재 필터링된 기록을 내보냅니다.

## 결과 읽는 방법

ID를 명단 소스 및 상태와 함께 사용하세요. 사용자 정의 명단이 기록을 재사용하거나 팀 간에 플레이어를 이동하는 경우 일치하는 플레이어 이름만으로는 충분하지 않습니다. 하나의 샘플 레코드를 열고 모드에서 예상하는 대상 폴더를 확인한 후에만 필터링된 테이블을 내보냅니다.

## 문제 해결

> **자주 발생하는 문제:** 사이버페이스가 잘못된 플레이어에 로드됩니다..

### 잘못된 플레이어가 얼굴을 받았습니다.

명단 소스와 플레이어 ID를 함께 확인하세요. 명단 세트 전체에 중복된 이름이 존재할 수 있습니다.

### 플레이어가 누락되었습니다.

팀 및 신인 필터를 제거한 다음 선택한 명단 데이터를 새로 고칩니다.

### 내보낸 경로가 잘못되었습니다.

ID를 복사하거나 내보내기 전에 선택한 기록에서 mod-folder 루트를 검토하세요.

## 데이터 및 복구

데이터베이스는 명단 파일을 변경할 필요가 없습니다. 필터링된 ID를 별도의 모드 작업 공간으로 내보내고 내보내기와 함께 소스 명단 라벨을 유지합니다.
