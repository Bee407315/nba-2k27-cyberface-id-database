## 為什麼需要這個工具

Cyberface 工作通常以玩家姓名開始，以 ID、資料夾路徑和名單檢查結束。瀏覽器將這些步驟保留在一處，並讓模組製作者僅匯出與他們正在編輯的名冊相關的記錄。

## 完成第一次使用

1. 開啟 **NBA 2K27 面補 ID 查詢**，確認偵測到的 NBA 2K27 版本或資料來源。
2. 選擇輸入或設定，只調整 **可搜尋的玩家 ID 索引**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **新秀和名單過濾器**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **mod資料夾和匯出註釋** 以便比對或還原。

## 開始之前

- 準備好 **球員或名單過濾器**，並確認它屬於目標 NBA 2K27 設定或連線。
- 變更設定之前，記錄目前遊戲/用戶端版本或資料日期。
- 先選擇 **CSV 或複製的 ID** 的儲存位置，避免覆蓋上一次結果。
- 先用 **可搜尋的玩家 ID 索引** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 主要功能

- **可搜尋的玩家 ID 索引.** 搜尋玩家姓名和 ID，無需強制進行精確拼字比對。

- **新秀和名單過濾器.** 依名冊、團隊、班級或記錄狀態縮小表格範圍。

- **mod資料夾和匯出註釋.** 複製一個乾淨的 ID 或匯出目前過濾的記錄。

## 如何理解結果

將 ID 與其名冊來源和狀態一起使用。當自訂名單重複使用記錄或在球隊之間移動球員時，匹配的球員姓名是不夠的。僅在開啟一條範例記錄並檢查 mod 所需的目標資料夾後匯出篩選表。

## 問題排查

> **常見問題:** 網路面孔載入到錯誤的玩家上.

### 錯誤的玩家收到一張臉

一起查看名單來源和玩家ID；名冊組中可能存在重複的姓名。

### 一名球員失踪

删除球队和新秀过滤器，然后刷新选定的名单数据。

### 導出的路徑錯誤

在複製或匯出 ID 之前，請檢查所選記錄中的 mod 資料夾根目錄。

## 資料與還原

資料庫不需要更改名冊檔案。將過濾後的 ID 匯出到單獨的 mod 工作區中，並在匯出時保留來源名冊標籤。

<sub>自動化與修改功能僅限遊戲規則和目前連線類型允許時使用。</sub>

## 遊戲更新之後
